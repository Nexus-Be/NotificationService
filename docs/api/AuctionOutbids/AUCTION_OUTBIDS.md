# Auction outbid logical notification
Status: VERIFIED — local backend automated tests,2026-11-08; Auction/client/provider integration pending.

## Scope,API and responsibility
First auction substep: BidOutbid only. Winner/payment instruction email,cancellation and payment-timeout notifications remain next. POST /api/v1/notifications/auction-outbids Service/Admin trusted Gateway,16KiB/no-store,200 pure AuctionOutbidResponse. Auction calls after valid higher bid commits. Notification never places/validates bids,selects winner,charges money,changes reputation or enforces auction state. REST only. The previous highest bidder is target,not new bidder or Seller. Source owns actual bidder/order/auction truth,post-commit reliable REST retry and end-time changes.

GET /api/v1/notifications/auction-outbids/{notificationId},authenticated owner only,200 InAppNotificationItemResponse;anonymous401/unknown,foreign,deleted or non-outbid404. Owner Push-only detail supported;GET does not mark read. FCM already sends notificationId;client resolves payload and rechecks current Auction access/status before showing live price or permitting bid. No arbitrary URL/redirect. Current-price/countdown/live bid-list UI remains Auction/frontend responsibility.

## Strict request
Required nonempty sourceEventId,auctionId,triggerBidId,previousBidId,previousHighestBidderUserId,newHighestBidderUserId,sellerUserId GUIDs. Bid IDs different;three user IDs distinct. AuctionTitle trimmed/nonblank<=200/no controls. PreviousAmount/NewAmount decimal18,2,positive and new>previous;currency fixed VND case-insensitive. OccurredAt UTC<=now+30sec,AuctionEndsAt>OccurredAt after anti-sniping extension as source committed (both required). Historical delivery allowed even past end: wording reports outbid/new amount at OccurredAt,does not claim still leading/auction running or invite stale bid. Optional trace<=100/no controls. Unknown JSON rejects raw tokens/private documents/arbitrary data/templates/URLs. Payload excludes Seller/new bidder identity per bid-history privacy.

Canonical hash includes all normalized business fields (amount fixed2digits,times UTC microseconds,title trim,currency VND),excludes trace. Event PK replay same ID/body=current states;changed409 AUCTION_OUTBID_CONFLICT. Unique TriggerBidId and PreviousBidId reserve one predecessor notification per accepted bid transition (append-only committed bid semantics). New event alias reusing either bid409 AUCTION_BID_ALREADY_NOTIFIED,including hidden receipts. Fresh valid bid/predecessor pair may notify same user again in same auction. Source maps aliases to original stable IDs. Generic dispatch key collision rejected,never adopt unknown content.
