# OrderPaid Buyer/Seller notifications
Status: VERIFIED — local backend automated tests,2026-11-08; Commerce/client/provider rollout pending.

## Scope and API
POST /api/v1/notifications/order-payments,Service/Admin through trusted Gateway,200 pure OrderPaymentResponse,16KiB/no-store. Commerce invokes only after regular single-seller order/suborder PAID commits,with stable sourceEventId/orderId. One checkout with multiple shops calls separately per seller suborder,never shares full checkout/seller-private data. Notification cannot verify payment/recipients or mutate order/wallet; source owns truth and durable REST retry. No broker/gRPC.

Required nonempty GUID sourceEventId,orderId,shopId,buyerUserId,sellerUserId (buyer!=seller);orderNo trimmed nonblank<=100/no controls;totalAmount decimal>0,<=9999999999999999.99,<=2decimal places;currency fixed VND (case-insensitive);paidAt required<=now+30sec;sellerAcceptDeadline required>paidAt,provided by Commerce (source enforces24h rule,Notification never restarts deadline). Historical paid events/past deadlines accepted; wording uses supplied UTC time. Trace<=100 optional/no controls. Unknown JSON rejected,no tokens/arbitrary template/data/URLs or password/documents. Stable proof includes all normalized business fields,excludes trace.

GET /api/v1/notifications/order-payments/{notificationId},any authenticated owner only,200 InAppNotificationItemResponse,404 unknown/foreign/deleted/non-order-payment item. Push data already carries notificationId;client resolves this resource to structured payload and routes to order detail. Owner GET supports Push-only records even when globally InApp disabled;target Commerce API still enforces order/shop permission. No arbitrary redirect URL. Does not mark read. Class controller has no role guard;POST service/admin,GET RequireRole.

Independent asynchronous branch/device outcomes;provider failure cannot rollback PAID or erase successful InApp. Both branches accepted atomically,precondition/template/schema errors accept neither;retry same event after fixing.
