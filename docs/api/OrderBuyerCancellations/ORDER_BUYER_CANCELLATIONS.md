# Paid regular order cancelled by Buyer
Status: VERIFIED — drafted before code;verified 2026-11-09.

## 1. Objective and source boundary
SRS Commerce functions60/72: cancellation after payment is eligible only before Seller hands goods to carrier;refund progress is separate. This step covers Buyer-initiated cancellation of paid Regular orders,including Shipping with label created but not handed over. Excludes unpaid/manual cancellation,Auction,Seller rejection/acceptance timeout/payment expiry,carrier cancellation and Admin/Staff interventions. Those events cannot be relabelled as Buyer cancellation. Source resolves payment/shipment/cancellation races and commits final cancellation,validates actor/ownership/eligibility/actual payment and no handover before durable REST retry. Notification does not cancel/refund/release stock/penalize or determine current state from prior notification receipts.
