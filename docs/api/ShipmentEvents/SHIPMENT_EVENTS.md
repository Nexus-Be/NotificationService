# Shipment lifecycle notifications
Status: VERIFIED backend — 2026-11-08; source/GHN/client/provider integration pending.

## Scope/source boundary
SRS Fulfillment120–126/F1-09/10/F4 shipping:Created,PickedUp,InTransit,OutForDelivery,Delivered,DeliveryFailed,Returning,Returned,Cancelled. Source Fulfillment normalizes verified GHN events and commits canonical state;REST only. Notify Buyer/Seller with optional Push/InApp;minimum SRS includes Buyer shipment-created/delivered and Seller failed delivery. Other audience/state notices are local optional channel policy,not asserted mandatory in SRS. Notification never calls GHN,creates shipment,marks order completed,credits/refunds wallets,restocks/applies reputation or independently verifies handover. Delivered is carrier-reported delivery,not Commerce completion/settlement. Returned/Cancelled no refund/stock promises. Source owns actual order/Seller/Buyer/auction/paid/accepted eligibility and durable immutable retry.
