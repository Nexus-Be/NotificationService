# Regular order payment-timeout notification
Status: VERIFIED — contract drafted before code; implementation verified 2026-11-09.

## Scope/source boundary
SRS F1-07:regular PendingPayment order expires without matched payment,source cancels order and notifies Buyer. REST only. Not auction Winner timeout or paid-order Seller acceptance timeout. Source Commerce resolves payment/expiry race,confirms committed regular-order cancellation and final unmatched-payment expiry,actual Buyer/order and original deadline before durable immutable retry. Notification validates declared shape,not banking/source truth;does not run expiry jobs,cancel orders,release stock/refund/apply reputation or assume Buyer never transferred money. Unmatched/late bank transfers may need source reconciliation,not a payment-again instruction in this notice.

## API/input
POST /api/v1/notifications/order-payment-timeouts Service/Admin trusted Gateway,16KiB/no-store,200 OrderPaymentTimeoutResponse. GET /{notificationId} authenticated Buyer owner,200 InAppNotificationItemResponse,no auto-read,anonymous401/foreign/deleted/non-feature404,Push-only active detail allowed.
Required nonempty sourceEventId,orderId,buyerUserId;OrderKind Regular(case-insensitive only),OrderNo nonblank<=100/no controls. Required OrderStatus Cancelled,PaymentStatus Expired(case-insensitive canonical). PaymentStatus asserts unmatched final expiry,not proof no transfer occurred. Required OrderCreatedAt<PaymentDeadline<=serverNow,PaymentDeadline<=CancelledAt<=now+30s,UTC microseconds. Historical notices retain original times,no duration derived/restarted (source owns Q32/Q34 configured deadline,not auction24h). TraceId optional<=100/no controls. Strict unknown JSON rejects auction/result/bid/Seller/acceptance-clock fields,money/paid/ledger/refund/stock/points/bank/contact/URL/password/OTP/token/private docs. Caller cannot use for other cancellation causes or authoritative Paid/Refunded order;source owns actual state and corrections.
